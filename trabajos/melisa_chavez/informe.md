# 📊 Informe de Base de Datos

## 1. Descripción general

La base de datos utilizada en esta práctica es **BDventas**.

El objetivo principal es gestionar la información relacionada con clientes, comerciales y auditorías dentro de un sistema de ventas.

La práctica se realizó utilizando MySQL Workbench y GitHub para el análisis y documentación de la base de datos.

---

## 2. Estructura

### 📁 Tablas principales

La base de datos está compuesta principalmente por las siguientes tablas:

- `clientes`
- `comercial`
- `auditoria`

### 🔗 Relaciones

Durante el análisis realizado no se observaron relaciones claramente definidas entre las tablas en el modelo conceptual, por lo que no se realizaron consultas JOIN.

---

## 3. Análisis

### ✅ Aspectos positivos

- La base de datos se encuentra organizada por tablas.
- Los nombres de los campos son comprensibles.
- La estructura permite realizar consultas básicas y filtradas.

### ⚠️ Aspectos menos claros

- No existen relaciones visibles entre las tablas.
- Algunas columnas podrían documentarse mejor.
- No se observan claves foráneas en el modelo conceptual.

---

## 4. Problemas detectados

- Falta de relaciones entre tablas.
- Modelo conceptual poco conectado.
- Dificultad para realizar consultas avanzadas con JOIN.

---

## 5. Propuestas de mejora

- Añadir claves foráneas para relacionar las tablas.
- Mejorar la documentación de los campos.
- Crear relaciones más claras entre clientes, comerciales y auditorías.
- Añadir nuevas tablas para ampliar el sistema de ventas.

---

## 6. Conclusión personal

Esta práctica permitió comprender mejor el funcionamiento de las bases de datos relacionales, el uso de MySQL Workbench y la creación de consultas SQL básicas y con condiciones.

También ayudó a entender cómo analizar la estructura de una base de datos y representar su modelo conceptual.
