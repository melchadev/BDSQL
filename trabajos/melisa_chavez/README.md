**BDventas**

## 📖 Descripción

Este proyecto consiste en el análisis y trabajo práctico sobre la base de datos **BDventas**, perteneciente al repositorio proporcionado para la asignatura de Sistemas Informáticos.

El objetivo principal es comprender el funcionamiento de una base de datos relacional utilizando herramientas como:

- 🐬 MySQL
- 🛠️ MySQL Workbench
- 🌐 GitHub
- 🧩 Consultas SQL
- 📑 Documentación técnica

---

## 📁 Contenido del trabajo

Este proyecto incluye:

- ✅ Modelo conceptual de la base de datos
- ✅ Consultas SQL básicas y avanzadas
- ✅ Análisis técnico de la estructura
- ✅ Informe profesional
- ✅ Archivos organizados en GitHub
